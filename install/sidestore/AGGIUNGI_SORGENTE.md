# Aggiungi InMoto su SideStore

Dopo aver installato SideStore sul tuo iPhone, puoi installare e
aggiornare InMoto direttamente dall'app — senza computer.

## Aggiungi la sorgente

1. Apri **SideStore** sull'iPhone
2. Vai nel tab **Browse** (in basso)
3. Tocca l'icona **+** (in alto a destra)
4. Incolla questo URL:

```
https://raw.githubusercontent.com/ruggerodivito-moto/InMoto/main/apps.json
```

5. Tocca **Add Source**
6. Cerca "InMoto" → tocca **Get** → **Install**
7. SideStore firma e installa l'app con il tuo Apple ID

## Aggiornamenti automatici

Ogni volta che viene pubblicata una nuova versione su GitHub,
SideStore mostrerà il badge di aggiornamento nella scheda **Updates**.
Tocca **Update** per installare la versione più recente.

## Rinnovo automatico certificato

SideStore rinnova il certificato dell'app ogni 7 giorni in background
tramite WireGuard. Assicurati che WireGuard sia attivo:

**SideStore → Impostazioni → Enable WireGuard → ON**
